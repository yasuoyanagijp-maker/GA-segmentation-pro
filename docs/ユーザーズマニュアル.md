# GA Segmentation ユーザーズマニュアル

FAF と Optos の画像で、地図状萎縮（GA）の範囲を測り、中心窩までの距離と時点間の進行を出すための手順です。

## 1. 二つのアプリ

同じフォルダにアプリが2つあります。画像の種類で使い分けます。

**GA Segmentation Pro**（`./run_flet.sh`、ポート 8551）

FAF 画像向けです。乳頭の両端、または画像の幅（mm）からスケールを付けます。1枚の解析と、複数時点の位置合わせ（Registration）ができます。

**GA Segmentation Optos**（`./run_optos.sh`、ポート 8552）

Optos 超広角画像向けです。乳頭の中心を1回、中心窩を1回クリックします。その2点の距離を 4.76 mm として、その画像だけのスケールを計算します。別の時点や、画面のズームには使い回しません。第1グレーダー、第2リーダー、最終読影者の3人で同じ画像を測れます。

どちらもアプリのウィンドウが開きます。メニューバーや Dock には **Flet** と出ることがあります。計測画面のタイトルは「GA Segmentation Pro」または「GA Segmentation Optos」です。

ブラウザで使いたいときだけ、起動コマンドの前に `FLET_USE_WEB=1` を付けます。

対応する画像は `.tif` `.tiff` `.png` `.jpg` `.jpeg` `.gif` です。

## 2. ソースから起動する

この Mac でリポジトリから開く手順です。Python は 3.12 を使います。

```bash
brew install pyenv
pyenv install 3.12.9
cd ~/GA-segmentation-pro
pyenv local 3.12.9
python3 -m venv myenv
source myenv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
./run_flet.sh
```

Optos は `./run_optos.sh` です。2回目以降は `source myenv/bin/activate` のあと、使いたい方のスクリプトだけ実行します。

`python3 --version` が 3.12 であることを確認してから仮想環境を作ります。

## 3. Mac に入れる

配布された ZIP を使うときです。中身は次のとおりです。

- `GA Segmentation Pro.app` または `GA Segmentation Optos.app`
- `インストール.command`
- `Macインストール手順.txt`

1. ZIP をダブルクリックして展開します。
2. 展開したフォルダで `インストール.command` を右クリック（または Control + クリック）し、「開く」を選びます。
3. 初回は「開発元を確認できないため開けません」と出ることがあります。そのときも右クリック →「開く」で続行します。
4. インストーラーは、この Mac 上で隔離属性を外し（`xattr -cr`）、アドホック再署名（`codesign --sign -`。Hardened Runtime は付けない）してから、Applications にコピーして起動します。Apple の公証は使いません。
5. 次回からは Applications のアプリをダブルクリックします。

`インストール.command` と `.app` は同じフォルダに置いたまま実行します。

開けないときは、ターミナルで次を実行してから起動し直します。`xattr` のあと、必ず `codesign` まで実行します。

```bash
xattr -cr "/Applications/GA Segmentation Pro.app"
codesign --force --deep --sign - "/Applications/GA Segmentation Pro.app"
```

Optos の場合はアプリ名を `GA Segmentation Optos.app` にします。

## 4. Windows で開く

64 bit の `GA Segmentation Pro.exe` と `GA Segmentation Optos.exe` です。署名がないため、初回は SmartScreen が表示されます。ウィンドウが開けば、その exe がアプリ本体です。

## 5. GA Segmentation Optos の操作

画面右上の「次にすること」が、いま行う操作です。それに従います。

### 5.1 フォルダを開く

読影担当で「第1グレーダー」を選び、「画像フォルダを開く」を押します。入力欄に絶対パスを入れて「開く」でも同じです。

1つのフォルダに、その眼の画像だけを入れてあるときは、そのフォルダが1症例です。中の画像が時点です。

症例ごと、眼ごとにフォルダを作ってあるときは、それらの親フォルダを開きます。直下の各フォルダが1症例になり、その中の画像が時点です。右眼を `OD`、左眼を `OS` というフォルダにしてあると、症例の一覧にその2つが出ます。切り替えは画面の「症例」と「時点」です。親フォルダの直下に置いた画像は「未分類」になります。

### 5.2 1時点を測る

1. 「乳頭」のまま、乳頭の中心を1回クリックします。中心窩の仮点が付き、この画像だけのスケールの下準備ができます。マスクはまだ出ません。仮点は乳頭から 4.76 mm 先です。
2. 「中心窩」で、中心窩らしい場所をクリックします。スケールは、その時点の乳頭中心から中心窩までを 4.76 mm として計算します。マスクはその位置で出ます。他の時点には使いません。
3. 中心窩を動かし直したあとは「再セグ」を押します。最初のクリックでは押しません。
4. 境界を直すときは道具を使います。
   - **縁まで** … クリックした位置から萎縮の縁まで広げます。
   - **塗る** … 萎縮として足します。
   - **消す** … マスクから削ります。
   - **範囲消去** … ドラッグした範囲を外します。
   - **移動** … 中心窩を置いたあとに、画像をずらして見ます。
   - **取消 / やり直し** … 直前の編集を戻します。
   - 道具を閉じてもマスクは残ります。
5. その時点でよければ「この時点を確定」を押します。中心窩をクリックし、乳頭とマスクが揃っている必要があります。マスクが空のときは確定できません。

黄斑窓のシアンの円が、定量に使う中心 6 mm です。黄の円は乳頭です。表示倍率は 1x、2x、4x です。1x では中心 6 mm の円が画面に収まります。

### 5.3 次の時点と進行

次の時点は一覧から開きます。また乳頭の中心から始めます。撮影のズームが違っても、時点ごとにスケールを付けます。

確定が2時点以上になったら「時系列を計算」を押します。その前に年齢と性別を入れると、令和5年簡易生命表から余命も出ます。

出る値は、時点ごとの √面積、GAWAIN、中心窩までの距離、中心 1 mm に残っている網膜です。中心窩までの隙間が 250 µm より小さいときは到達年数を出さず、中心 1 mm の残存の変化を出します。

一覧の黄色は、前の時点より逆行している時点です。その時点のマスクと中心窩を見直し、必要なら「再セグ」します。

検査日時は欄に入れて「日時を反映」します。

### 5.4 保存

「個別CSV」はその症例の時点ごとです。「時系列CSV」は進行を1行にまとめたものです。どちらもダウンロードフォルダに保存されます。ファイル名は `GA_optos_` で始まります。

### 5.5 3人で読む

読影担当を切り替えると、ボタンと説明が変わります。

**第1グレーダー**

画像フォルダを開いて測り、「第1読影を書き出す」を押します。開いたフォルダが、書き出しの親になります。

**第2リーダー**

「第1の出力フォルダを開く」で、第1グレーダーが書き出したフォルダ（export の親）を選びます。第1のマスクは開きません。同じ画像を測り直し、「第2読影を保存」のあと「統合解析データ」で採用する CSV を作ります。

**最終読影者**

RECHECK の `*_summary.md` を選ぶと、そこに書かれた画像だけが開きます。測って「最終読影を保存」し、「トライアッド確定」で中央値を書き出します。他の読影者の値は画面に出しません。

## 6. GA Segmentation Pro の操作

左がフォルダと条件、中央が画像、右が数値です。

### 6.1 画像を開く

1. 入力フォルダを指定します。フォルダのアイコンからも選べます。
2. 出力フォルダを指定します。CSV と PDF はここへ保存します。
3. 「画像リストを読込」を押します。
4. 複数の症例が混ざっているときは「症例」で切り替えます。新しい名前を入れて「症例を作成」すると、選んだ画像をそちらへ移せます。

画像モダリティとスケールの基準は、読み込んだ画像に合わせます。

- Optos 相当の画像は、既定が DFD 4.76 mm です。乳頭の両端と中心窩からスケールを計算します。乳頭径（µm、初期値 1800）で固定することもできます。
- HRA は「①' 幅指定」を先に行い、画像幅（mm）を入れます。乳頭が見えるときは端点も指定できます。

年齢と性別を入れると、時系列の結果に余命が足されます。出典は令和5年簡易生命表です。

### 6.2 1枚を解析する

ツールバーの順に進めます。

1. **⓪ クロップ**（任意）。黄斑の近くを矩形で切り出します。
2. **① 乳頭**。視神経乳頭の端を2点クリックします。HRA で幅を使うときは **①' 幅指定** を先にします。
3. **② 中心窩**。中心窩を1点クリックします。シアンの十字が付きます。
4. **③ 解析**。GA の範囲を自動で作ります。

右のパネルに合計面積、病変ごとの面積、GAWAIN、中心窩までの距離が出ます。境界を直したあとは「↻ 再解析」です。暗い病変が足りないときは「↻ 高強度で再解析」があります。

CLAHE は既定でオンです。オフにするとマスクが大きくなりやすいです。clip を上げると面積は縮みやすいです。

中央の表示は「作業」「GIF」「グラフ」で切り替えます。

### 6.3 複数時点

1. 「時系列モード（Registration）」をオンにします。
2. 各画像の検査日時を入れ、「確定」を押します。ファイル名や EXIF から入っているときも、未確定の表示なら確定します。
3. 各画像で、乳頭（HRA は幅指定）と中心窩を付け、準備確定します。この段階では、位置合わせの前にセグメンテーションを走らせません。
4. 対象にする画像にチェックを入れ、「④ Registration」を押します。位置合わせは、同じ症例の中だけで行います。
5. 結果を確認し、「確認完了 → 結果表示」で数値に戻します。

時点の移動は「◀ 前の時点」「次の時点 ▶」です。まだ解析していない画像へ進むときは「次の未解析へ ▶」です。

「CSV 保存」と「PDF ダウンロード」は、④ のあとで使います。保存先は出力フォルダです。

進行速度（µm/年）は、複数時点の中心窩距離から計算します。欄に手で入れる値は、時系列を実行すると上書きされます。

## 7. 数値の意味

| 項目 | 意味 |
|---|---|
| スケール (µm/px) | Optos は乳頭中心–中心窩を 4.76 mm とした値。Pro では乳頭径（既定 1800 µm）で割る方法も選べる。HRA は画像幅 (mm) |
| GA 面積 | マスクの画素数を mm² に換算した値。24 mm 相当の面積欄を出すことがある |
| √面積 | 面積の平方根。時点間の進み方を見る |
| GAWAIN | 中心窩を中心にした半径 3 mm を、0.05 mm 刻みの 60 環に分け、萎縮の占有に重みを付けた指数（0–100） |
| 中心窩まで | 中心窩から GA までの最短距離 |
| 縁まで | 中心窩と萎縮縁の隙間 |
| 中心 1 mm | 中心 1 mm に残っている網膜の面積。隙間が 250 µm より小さいときは、到達年数の代わりにこの変化を見る |
| 到達年数 | 中心窩までの距離を、進行速度（µm/年）で割った年数。隙間が 250 µm より小さいときは出さない |
| 余命 | 年齢と性別から、令和5年簡易生命表を引いた値 |

黄色の時点は、前の時点より値が逆行しています。マスクと中心窩を見直します。

## 8. 開かないとき

**ウィンドウが出ず、ブラウザだけ開く**

配布したアプリ、および `./run_flet.sh` と `./run_optos.sh` はウィンドウで開きます。ブラウザにするときだけ `FLET_USE_WEB=1` を付けます。

**Dock が Flet になる**

計測ウィンドウを表示しているプロセスの名前が Flet です。ウィンドウタイトルで、Pro か Optos かを区別します。

**`flet: command not found` や import エラー**

仮想環境が有効ではありません。

```bash
cd ~/GA-segmentation-pro
source myenv/bin/activate
pip install -r requirements.txt
```

**Pillow のインストールに失敗する**

Python 3.14 が選ばれています。`python3 --version` が 3.12 になるよう `pyenv local 3.12.9` してから、仮想環境を作り直します。

**ポートが使用中**

Pro は 8551、Optos は 8552 です。起動スクリプトは、自分のポートを空けてから起動します。強制してやり直すときは `GA_FORCE_RESTART=1 ./run_flet.sh` です。Optos も同様に `./run_optos.sh` へ付けます。

**Mac で「開発元を確認できない」**

ダブルクリックでは開きません。セクション 3 のとおり、`インストール.command` を右クリック →「開く」で実行します。Applications に入ったあとも同じ警告が出るときは、セクション 3 の `xattr` と `codesign` を実行します。
